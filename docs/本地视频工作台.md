# 本地视频工作台

本模块为本项目自研，不内嵌、不调用 Dousnap，不是其官方私有部署版本。

## 使用

启动原工作台 `npm start`，在 `http://127.0.0.1:5188/` 左侧打开“全网视频采集”。选择要完成的操作，选择已有素材或粘贴公开视频链接，点击开始处理。素材库可搜索记录、查看结果、暂停、重试、移除；移除只归档记录，不删除磁盘文件。单文件上限5 GB（5 × 1024³ 字节）；浏览器视频下载采用流式写盘。

本机功能：视频/音频转写及SRT字幕、图片OCR、文案总结、开头和脚本改写、翻译、素材问答、系统配音、参考音色配音、封面模板排版。抖音/小红书视频使用已登录的本机浏览器读取对应作品，其余平台使用 yt-dlp，支持范围受其解析器和各平台当前访问策略影响，不保证每个平台或私密链接可下载；遇登录/验证可将已取得的视频上传处理。

配音和文案模型均在本机推理。首次处理会加载模型，重型任务顺序执行。使用自己的或获授权的参考声音；输出AI文案需核对事实。

## 运行位置

- 独立Python环境 `.runtime/video-env`；依赖锁 `src/bridge/video-requirements.lock.txt`。
- OCR可执行文件 `.runtime/video-ocr`，使用系统Vision框架。
- 数据库、上传和输出 `.runtime/video-workbench/`，与原评论数据库分离。
- 全局已有模型缓存 `~/.cache/huggingface/hub/`，仅复用，不改动：`mlx-community/whisper-base-mlx`、`mlx-community/Qwen3.5-9B-OptiQ-4bit`、`mlx-community/Qwen3-TTS-12Hz-1.7B-Base-bf16`。
- ffmpeg `~/.local/bin/ffmpeg`，配音 `/usr/bin/say`。
- 模型推理进程开启Hugging Face离线模式；下载平台视频需要网络。

重新准备本机环境：`npm run setup:video`。该命令安装独立依赖并编译OCR，不自动下载模型。当前环境为 Apple Silicon macOS；其他系统需替换MLX、Vision和系统配音实现。

## 范围与验证

已验证本机中文转写、SRT、总结、图片OCR、系统配音、参考音色合成、封面模板排版，浏览器完整配音流程与播放范围请求、导航草稿保留、移动端布局。测试产物在 `output/verification/local-video-*`。

当前封面功能为排版工具，不是AI图像生成或对参考封面风格的完整复刻。素材库目前按名称/正文检索，尚未提供网站同等的网络选题检索与分组功能。网站其余未核实的视频AI工具不在当前已实现范围内。真实平台视频下载仍需逐平台实测，不能把本地处理通过等同于全网采集通过。

源码和依赖许可证以各项目为准：yt-dlp、MLX-LM、MLX-Whisper、MLX-Audio及各模型权重分别遵循其许可。


## 2026-10-04 采集修复与板块入口

11项处理操作改为卡片入口，素材记录也使用卡片。所有操作提供源链接：先提取媒体，再转写、总结、改写或生成声音；图片识别/封面排版可提取视频首帧。源链接优先于旧的素材选择，手填正文仍可作为生成内容。参考音色链接自动取前20秒及参考文字。长文本超过单次上限会提示分段，已提取的视频仍可下载与复用。

macOS 浏览器采集沿用现有系统 HTTPS 代理；仅匹配源作品 ID 的媒体，排除推荐和登录背景视频。已实测原失败的抖音短链接下载到68.87秒视频，约12.5MB，标题为“别再乱搜剪映音效！90% 新手都踩坑”，并完成中文转写/SRT。转写为机器识别，存在错字，使用前需要校对。小红书等其他平台仍需逐平台实测，登录/验证码按平台页面手动完成。
